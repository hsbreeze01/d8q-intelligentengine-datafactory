> 代码: `sentiment.py` · 表: `sentiment_daily` + `sentiment_extras_daily` + `sentiment_sector_daily` · API: `/api/macro/sentiment` · 前端: 主看板「宏观仪表盘」tab

## 0. 背景与调研结论（2026-08-26 调研）

对标短线选手「爱在冰川」的市场情绪图体系，调研结论：

| 层面 | 公开程度 | 结论 |
|---|---|---|
| 情绪周期理论（冰点→回暖→发酵→高潮→分歧→退潮） | ✅ 完全公开 | **采纳**，作为阶段映射框架 |
| 私有「情绪温度计」模型（12 指标：股吧恐慌指数、龙虎榜游资净买入、期权波动率等） | ❌ 构成/权重从未公开 | **不复刻**——一半指标依赖社交爬虫/Level-2/期权数据，我们没有 |
| 社区/券商金工通行量化口径（涨停家数/连板高度/晋级率/封板率/昨涨停溢价） | ✅ 公开 | **复刻**——100% 可由现有日线推导 |

**定位**：与缠论信号互补——缠论是「个股结构」视角，情绪温度计是「市场环境」视角（环境不对就不出手）。

## 1. 总体架构（已实现）

```
stock_data_daily (MySQL, 5200只, 2024-01-02起, 日线OHLC)
    │  sentiment.py (pandas 分批流式, 每批300只, 内存有界)
    ▼
sentiment_daily 表 (每日17指标 + 合成指数 + 阶段)
    │  /api/macro/sentiment?days=N (默认250, 升序返回)
    ▼
主看板「🌐 宏观仪表盘」tab (板块化布局, 情绪=板块1, 后续板块可插)
```

- 计算: `venv/bin/python sentiment.py`（重算近 30 天，幂等 REPLACE）/ `--backfill`（全量）/ `--days N`
- 回填: 642 个交易日一次完成（~2.5 分钟）

## 2. 指标口径（已实现，全部可复算验证）

### 2.1 基础判定
- **涨停价** = `round(prev_close × (1 + 板块比例), 2)`；30/68 开头 20%，其余 10%；跌停对称
- **相邻交易日链**：仅当该股上一条记录为相邻市场交易日才 chain（停牌复牌断档重置连板）
- **数据清洗**（上游缺陷防御）：
  - `stock_data_daily` 存在采集器重复插入（同一 stock-day 2~9 条副本，共 38 万冗余行）→ 按 `(stock_code, date)` 去重取最早副本
  - 涨跌幅**自算**（`close/prev_close - 1`），不信任采集器 `change_percentage`（副本间数值不一致）

### 2.2 每日 17 指标

| 指标 | 口径 | 情绪含义 |
|---|---|---|
| limit_up / limit_down / touch_limit | 收盘涨停 / 收盘跌停 / 盘中触涨停家数 | 最粗温度 |
| seal_rate | limit_up ÷ touch_limit | 封板率，>70% 强势 |
| max_streak | 全市场最高连续涨停天数 | 空间天花板（抬升=升温，压制=退潮） |
| streak_dist | JSON `{"1":首板,"2":二板,"3":三板,"4+":四板以上}` | 连板梯队结构 |
| promo_1_2 / 2_3 / 3_up / overall | 昨N板今日继续涨停 ÷ 昨N板 | 情绪加速度（>50% 亢奋 / <30% 退潮） |
| premium_mean / median | 昨日涨停股今日涨跌幅均值/中位数 | 赚钱效应接力 |
| big_face | 昨涨停 & 今跌幅≤-9.8% 家数 | 大面票（退潮信号） |
| heaven_hell | 今盘中触涨停 & 收盘跌停 | 天地板（退潮确认） |
| up_ratio | 上涨家数占比 | 市场广度 |
| total_turnover | 全市场成交额（元） | 资金参与意愿 |

### 2.3 合成指数 composite（0-100）

- 六子指标按 **expanding 历史分位**标准化（`min_periods=60`，无未来函数，跨牛熊可比）：

| 子指标 | 权重 | 依据 |
|---|---|---|
| limit_up 涨停家数 | 0.20 | 赚钱效应核心 |
| promo_overall 综合晋级率 | 0.20 | 情绪加速度核心 |
| max_streak 连板高度 | 0.15 | 空间天花板 |
| seal_rate 封板率 | 0.15 | 封板意愿 |
| premium_mean 昨涨停溢价 | 0.15 | 接力发糖 |
| up_ratio 上涨占比 | 0.15 | 广度 |

- 行级权重归一：某子指标缺失（如当日无连板基数）时按可用权重归一，不产生空洞
- **phase 阶段映射**：<20 冰点 / <40 修复 / <40~60 温和 / <80 亢奋 / ≥80 过热（附 composite_ma5 平滑）

### 2.4 验证记录
- **外部基准**（新浪 2026-08-24 公开数据）：涨停 45 vs 48（差值=ST 5% 板不可识别）；**2板/3板/4板梯队 6/3/1 精确吻合；晋级率 13.3%/27.3% 精确吻合**
- **极端日符合史实**：2024-09-26 / 09-30「924 行情」识别为过热（97.79 / 95.55）
- 当前样例（2026-08-26）：温和 53.26，涨停 56，最高 5 板，封板率 68.3%，昨涨停溢价 +2.4%

### 2.5 v2 补充指标（已上线，2026-08-27）

**采集**（AKShare EOD，独立表 `sentiment_extras_daily`，`--collect-extras` 触发，各组失败容忍不阻断 v1）：

| 组 | 接口 | 口径 | 可回填性 |
|---|---|---|---|
| lhb 龙虎榜 | `stock_lhb_detail_em`（按月区间） | 家数 / 净买合计（元→万，按代码+上榜日去重）/ 机构席位次数（解读含"机构"） | 2024-01-02 起全量 |
| margin 两融 | `stock_margin_sse`（区间）+ `stock_margin_szse`（逐日） | 沪+深 融资余额 / 融资买入额（亿；两源齐全才写，T+1 发布次日自动补） | 全量 |
| broken 炸板池 | `stock_zt_pool_zbgc_em`（逐日） | 炸板家数（空表=当日无炸板记 0） | 仅近 ~30 交易日 |
| 北向净买额 | ~~停发~~ | 2024-08-18 起港交所停发日度披露，**不采集** | — |

**派生与合成**：
- `true_seal_rate` 真实封板率 = 收盘涨停 ÷（收盘涨停 + 炸板），修正日线 proxy 低估（仅近 30 日有值）
- `composite_v2` / `phase_v2`：九子指标加权（v1 六指标等比缩放 0.70 + 龙虎榜净买 0.15 + 真实封板率 0.10 + 融资余额 0.05），同样 expanding 分位 + 行级权重归一；**extras 全缺的历史段 composite_v2 == composite，曲线连续无断点**
- 阶段映射与 v1 相同（phase_v2）

**运行**：
```
venv/bin/python sentiment.py --collect-extras                      # 每日增量(采集近30缺口+重算近30日)
venv/bin/python sentiment.py --collect-extras --extras-backfill    # 全量回填(一次性)
venv/bin/python sentiment.py --collect-extras --only lhb           # 单组修复(不计算)
```

### 2.6 v3 P0/P1 指标（已上线，2026-08-27）

对标冰川每日图的缺口补全：7 个指标全部**纯 DB 推导、零新增采集**，在 `_process_batch` 批内流式聚合（复用 range-scan 有界内存），任意运行模式（增量/`--backfill`/`--collect-extras`）都会计算并持久化。

**P0（当日看盘必备）**

| 指标 | 口径 | 对标 |
|---|---|---|
| `chg_dist` | 涨跌幅 21 档分桶 JSON（桶 i 覆盖 [i, i+1)pp，clip ±10；**分桶前 round 2dp**——涨停股 close/prev-1 常为 9.9999999998% 之类浮点尾差，不 round 会散落 b9/b10 桶） | 冰川图1 柱状图 |
| `up_count / down_count / flat_count` | 收盘涨/跌/平家数（涨跌幅自算口径，非采集器列） | — |
| `mkt_chg_mean / mkt_chg_median` | 全市场平均涨幅 / 中位数（中位数用直方图桶内线性插值近似） | 冰川图2 |
| `sentiment_sector_daily` 表 | 申万一级行业日频聚合：成交额 / 家数 / 涨家数 / 均涨幅 / 龙头股（代码+名称+涨幅）；行业取 `stock_basic.industry` 一级（`-` 前段），缺失归「未分类」 | 冰川图4 板块成交额榜 |

**P1（接力质量增强）**

| 指标 | 口径 | 对标 |
|---|---|---|
| `premium_mean_noyizi / _median_noyizi` | 昨涨停溢价**剔除今日一字开盘**（今开 ≥ 涨停价-0.001 的剔除）——区分自然接力 vs 一字躺赢 | — |
| `lb_strength` 连板值 | 昨连板（≥2板）股今涨幅 ≥7% 的比例（宽松接力口径） | 冰川图5 |
| `lb_break` 连比值 | 昨连板股今涨幅 ≤0 的比例（断板收平/跌，连板梯队韧性的反向指标） | 冰川图5 |

**实现与验证**：
- 板块表 PK `(date, industry)`，`persist_sectors` 整日先删后插幂等，只保留最近 tail_days 个交易日；原值即用，无 60 日分位 warm-up 问题
- API：`/api/macro/sentiment` 返回新增 `sectors` 字段（最新交易日按成交额 TOP8；表缺失时容忍返回空数组，不阻断 v1）
- 单测：`tests/test_sentiment_v3.py`（FakeCur 模拟 ORDER BY 排序；覆盖 21 档分桶含浮点精度、非一字溢价、连板值/连比值、板块聚合与龙头）
- 已知取舍：`lb_strength` 用 ≥7% 宽松口径（严格口径应「今涨停或≥7%」且剔除一字，样本量小噪声大，先宽后紧）

## 3. 前端（已实现）

- 主看板 SPA（`templates/index.html`）`PAGES` 注册 `macro` tab，`loadMacro(el)` 渲染
- **板块化布局**：外层可扩展容器，情绪是板块 1/1，后续宏观板块（资金面/北向/估值）追加即插
- 内容：阶段徽章（颜色+分数+操作提示）→ 8 指标卡 → 情绪指数主图（ECharts，分色+阈值线+缩放）→ 连板高度/涨跌停副图
- **趋势窗口 30/90 切换**（默认 90，2026-08-27 实证定标：584 日序列实测情绪周期中位 54 自然日≈37 交易日，90 日≈1.5~2 个完整周期可判位置，30 日看拐点；数据一次拉 90 日，30 由前端切片零二次请求）
- **v2 元素**（紫色系区分）：v2 阶段徽章（龙虎榜/两融/炸板池融合，悬停提示口径）→ 3 张补充指标卡（龙虎榜净买/真实封板率/融资余额）→ 主图新增「情绪v2」紫色曲线（与 v1 同图对比）
- **v3 元素**（P0/P1）：3 张 P1 指标卡（涨/跌/平家数+均涨中位、连板值/连比值、非一字溢价）→ 「全市场涨跌幅分布」21 档柱状图（红涨绿跌，悬停显示桶区间家数）→ 「板块成交额榜」TOP8 卡片（行业+均涨幅分色背景+成交额占比+涨家数占比+龙头股）

## 4. 未实现部分（Roadmap，按优先级）

### 情绪闸门接入模拟器（优先级最高，半天）
- **设计**：模拟器按 phase 客观调整买入纪律——
  - 冰点期：`BUY_MIN_SCORE` 60→70（或仅允许错杀修复类买点）
  - 亢奋末期/过热：不开新仓，只执行卖出纪律
  - 退潮确认信号（big_face 批量出现/天地板）：同过热处理
- **实现路径**：47 暴露 `GET /api/macro/sentiment/latest`（或 JD 直连 MySQL 读 `sentiment_daily` 最后一行）→ JD `executor.process_buys` 前置闸门；全部写成规则，零主观
- **配套**：每日 journal 头部加情绪标签；周报 3×3 统计按情绪阶段分组，验证缠论信号在不同情绪环境的胜率差异
- **前置条件**：情绪数据积累观察一段时间后启用（阈值需要实证校准）

### 盘中实时版（真正的「实时」，暂缓）
- 现状 v1 为 EOD（21:30 收盘后计算）
- 盘中版需要分钟级数据或全市场快照轮询（OpenD snapshot 5200 只 ≈ 52 批/次，限频；或 akshare 盘中接口）
- 价值：盘中炸板率/触板数的实时变化 → 情绪拐点早发现；成本高，待 v2 验证价值后再议

### 企微每日播报（小，随手）
- 复用现有 qyapi webhook 模式，每日 21:35 推送：情绪分+阶段+环比变化+晋级率/封板率关键数字

### 题材梯队维度（进阶）
- `t_concept_board_daily` 数据已在库：可做板块维度情绪（涨停板块分布/轮动速度/主线持续天数）

### 明确不做
- 复刻冰川私有 12 指标：股吧恐慌指数（爬虫）、龙虎榜游资净买入（实时龙虎榜）、期权波动率（期权数据）、封单额/盘中开板次数（Level-2）——数据不可得，投入产出不成比例

## 5. 已知局限（接受或待治理）

| 局限 | 影响 | 处置 |
|---|---|---|
| 炸板率为日线 proxy（盘中开板回封不可见） | 炸板率被低估 | 接受（国信金工口径同样局限）；盘中版可解 |
| ST 股 5% 板不可识别（库中无 ST 标记） | 涨停家数低于公开口径 ~3 家 | 接受，对指数影响可忽略 |
| 北交所 30% 板不在库 | 天然排除 | 接受 |
| 分位 warm-up 前 60 日 composite 为 NULL | 2024-01~2024-04 无合成指数 | 接受（历史越往后越准） |
| **`stock_data_daily` 38 万重复行**（采集器重复插入，根因未治） | 采集器侧持续产生，情绪脚本靠去重防御 | **待治理**：清重后加 `(stock_code, date)` 唯一键（需停写窗口） |
