# P0 - 自选股日报与评分变化

## 概述

为D8Q平台自选股功能增加每日评分跟踪与变化报告能力，让用户一目了然地掌握持仓/关注股票的评分动态。

## 背景与动机

### 当前状态
- 自选股功能已上线：用户可通过 GET/POST/DELETE `/api/watchlist` 管理自选股列表
- 前端 `loadStock()` → `loadWatchlist()` 渲染简单 grid（仅显示代码、名称）
- 综合分析 API `POST /api/stock/comprehensive` 已可返回单只股票的多维评分
- Shark 服务（49.234.48.221:5000）提供每日推荐含技术评分
- SQLite `financial_news.db` 已有 `watchlist` 表（user_id, stock_code, stock_name）

### 痛点
1. 用户需逐只点击才能查看综合评分，无法批量感知变化
2. 无历史评分记录，无法追踪股票评分趋势
3. 评分变化缺乏归因，不知道是哪个维度驱动了分数变化
4. 无法快速识别"今天变化最大的股票"

### 目标
- 每日自动为所有用户自选股计算并存储评分
- 前端自选股列表升级为带评分、趋势、信号的增强视图
- 提供7日评分 sparkline 走势图
- 支持评分变化归因分析

## 用户价值

| 用户场景 | 价值 |
|---------|------|
| 早盘前查看自选股日报 | 快速了解哪些股票评分大幅变化，优先关注 |
| 7日趋势一目了然 | 无需逐日记忆，sparkline 直觉展示走势 |
| 点击归因分析 | 知道是技术面、趋势、基本面还是量能引发变化 |
| 排序突出异动 | 变化大的排前面，节省注意力 |

## 优先级

**P0** — 核心用户体验提升，完善自选股从"管理"到"监控"的能力闭环。

## 范围

### In Scope
- `score_history` 表设计与创建
- 每日定时任务（08:30 计算评分）
- 日报 API（`GET /api/watchlist/daily-report`）
- 评分历史 API（`GET /api/watchlist/{code}/score-history?days=7`）
- 前端自选股列表改造（评分表格 + sparkline + 归因弹窗）

### Out of Scope
- 推送通知（评分大幅变化时的飞书/邮件通知）
- 多用户隔离的评分计算优化（当前单用户场景）
- 评分模型本身的调优
- Shark 推荐与自选股日报的融合视图

## 成功指标

- 定时任务每日 08:30 成功执行率 > 99%
- 日报 API 响应时间 < 500ms（30只自选股以内）
- 前端自选股页面加载完成 < 2s
- 用户可在首页直接看到评分变化排序列表
