# D8Q 智能资讯平台 V2.0 — 产品需求文档 (PRD)

> 版本：2.0 | 日期：2026-06-30 | 状态：规划中

## 1. 产品愿景

将 D8Q 从「信息聚合工具」升级为「主动智能投研助手」，实现三个核心转变：
- **被动查看 → 主动触达**：用户不用刷新，系统主动推送关键异动
- **分析孤立 → 决策闭环**：分析 → 模拟执行 → 复盘验证 → 优化迭代
- **数据罗列 → 洞察归因**：不仅展示 what，更解释 why 和 so what

## 2. 目标用户

- 个人投资者（关注A股，侧重技术面+主题投资）
- 一级市场关注者（关注投融资动态，挖掘产业链机会）
- 量化/半量化爱好者（需要策略验证和信号系统）

## 3. V2.0 功能模块总览

| 优先级 | 模块 | 核心价值 | 预估工期 |
|--------|------|----------|----------|
| **P0** | 智能预警中心 | 从被动到主动，提升日活和粘性 | 5天 |
| **P0** | 自选股日报 + 评分变化 | 低成本高感知，核心用户每日必看 | 3天 |

| **P1** | 投融资数据增强 | 热力图+机构追踪，差异化竞争力 | 4天 |

## 4. 模块详述

### 4.1 智能预警中心 (P0)

**用户故事：** 作为投资者，我希望在自选股出现异动、赛道热度突增、重磅政策出台时，系统立即通知我，而不是我每天手动刷新10个页面。

**核心功能：**
- 统一预警 Hub 页面（所有类型预警汇聚）
- 预警规则自定义（个股价格/评分变化、赛道热度阈值、融资大事件）
- 分级推送（紧急=邮件+站内红点、重要=站内、一般=消息流）
- 预警历史 + 后续市场表现追踪
- 一键从预警跳转到详情分析

**关键指标：** 预警覆盖率 > 90%（重要异动触发预警），用户 3 日回访率提升 20%

### 4.2 自选股日报 + 评分变化 (P0)

**用户故事：** 作为投资者，我希望每天早上能看到自选股的综合状态变化，知道哪些票发生了重要变化，不用逐个点进去分析。

**核心功能：**
- 自选股列表增加「今日评分」「评分变化」「信号状态」列
- 评分变化趋势小图（sparkline，7日走势）
- 每日自动计算全部自选股的综合评分（复用现有 /api/stock/comprehensive）
- 变化排序：评分下降最多的排前面（风险优先）
- 一键查看评分变化归因（哪个维度导致分数变化）

**关键指标：** 自选股页日均停留时长从 30s 提升到 3min

### 4.3 持仓模拟/虚拟组合 (P1)

**用户故事：** 作为投资者，我希望能创建虚拟组合，记录我的买卖操作，跟踪组合收益和风险，验证我的投资逻辑。

**核心功能：**
- 创建多个虚拟组合（如"核心仓"、"短线博弈"）
- 模拟买入/卖出操作（指定价格、数量、日期）
- 实时计算组合：总市值、累计收益率、最大回撤、夏普比率
- 收益归因：按个股、按行业拆解贡献
- 组合 vs 基准（沪深300）对比曲线
- 历史操作记录 + 盈亏明细
- 导出组合报告

**关键指标：** 用户创建组合率 > 30%，周均操作 > 3次

### 4.4 推荐回溯验证 (P1)

**用户故事：** 作为投资者，我希望能看到系统过去推荐的股票实际表现如何，判断推荐系统是否值得信赖。

**核心功能：**
- 历史推荐列表（按日期分组）
- 每条推荐标注 T+1/T+3/T+5/T+10 实际收益率
- 整体命中率统计（推荐分数 > 70 的胜率）
- 按维度（技术/趋势/基本面/量能）的子维度胜率
- 推荐 vs 大盘超额收益曲线
- 失败案例复盘（分数高但跌幅大的原因分析）

**关键指标：** 推荐胜率可视化覆盖 > 95% 历史推荐

### 4.5 投融资数据增强 (P1)

**用户故事：** 作为关注一级市场的投资者，我希望通过热力图和机构追踪，快速发现融资热点和聪明钱的流向。

**核心功能：**
- 融资热力图：按月 × 行业 的事件密度 heatmap
- 融资趋势图：按月统计融资金额和事件数的趋势线
- 轮次分布饼图 + 平均金额分析
- 明星机构追踪：活跃 VC/PE 最近出手列表
- 用户可关注特定机构，该机构出手时预警
- 融资事件与赛道热度的相关性分析

**关键指标：** 投融资页面日均 PV 提升 200%

## 5. 技术架构概要

```
                ┌─────────────────────────────────────────┐
                │            Factory (8088)                │
                │  Flask SPA + Investment/Alert APIs       │
                └───────────┬────────────┬────────────────┘
                            │            │
              ┌─────────────┴──┐    ┌────┴───────────┐
              │  Agent (8000)  │    │  Shark (5000)  │
              │  投融资/资讯/   │    │  行情/技术/     │
              │  赛道/LLM       │    │  回测/推荐     │
              └────────────────┘    └────────────────┘
```

- **预警系统**：新增 `scheduler.py` 定时任务，每 30min 扫描预警规则，触发后写入 alerts 表
- **评分日报**：复用 Agent 的 `/api/stock/comprehensive`，新增 `score_history` 表存储每日评分
- **虚拟组合**：Factory 本地 SQLite 新增 portfolios/positions/trades 表
- **推荐回溯**：Shark 已存储历史推荐，新增 `/api/recommendation/history` 端点
- **投融资增强**：复用 Agent 的 itjuzi 数据，Factory 增加聚合统计 API

## 7. 风险与依赖

- **评分日报依赖 Shark API 的稳定性**：需要增加超时和降级逻辑
- **预警频率需要平衡**：太频繁用户疲劳，太稀疏失去价值 → 默认静默期 4h
- **虚拟组合的行情数据需要每日更新**：依赖 Compass 的每日数据同步
- **推荐回溯需要历史推荐数据积累**：当前数据量约 30 天，需持续积累
