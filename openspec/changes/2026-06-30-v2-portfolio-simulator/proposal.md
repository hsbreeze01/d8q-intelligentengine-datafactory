# P1 - 持仓模拟 / 虚拟组合

## 概述

为 D8Q 数据工厂平台新增「虚拟组合」模块，让用户无需真实资金即可创建模拟投资组合、执行买卖操作、跟踪持仓盈亏，并通过可视化看板评估投资绩效。

## 动机与背景

- 用户在使用 D8Q 的行情数据和选股工具后，缺少一个闭环验证环境来检验策略效果
- 市面模拟盘产品独立于数据平台，无法与现有行情/财务数据联动
- 本功能复用已有的 Shark 行情服务（实时报价）和 Factory 用户体系，零额外基础设施成本

## 目标

1. 用户可创建多个虚拟组合，各自独立初始资金
2. 支持 A 股模拟买入/卖出，自动计算持仓成本与浮动盈亏
3. 每日自动刷新持仓现价，生成净值序列
4. 提供组合绩效看板：净值曲线、最大回撤、夏普比率、vs 沪深300基准对比
5. 前端无缝集成到现有 SPA（PAGES 数组 + loadPage 模式）

## 非目标

- 不支持融资融券、期货期权等衍生品
- 不支持真实券商下单
- 不做社交/跟投功能
- 不做分钟级实时净值（每日频率即可）

## 成功指标

| 指标 | 目标值 |
|------|--------|
| 用户创建组合数 | 上线首月 ≥ 50 个 |
| 日均模拟交易笔数 | ≥ 20 笔 |
| 组合页面日均访问 | ≥ 100 PV |

## 风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Shark 行情接口不稳定 | 现价更新失败 | 增加重试 + 降级用上一交易日收盘价 |
| SQLite 并发写入瓶颈 | 高并发交易时阻塞 | 短期可接受，中期可迁移至 PostgreSQL |
| 沪深300基准数据源 | 无现成接口 | 复用 Shark 接口 symbol=sh000300 |

## 时间规划

| 阶段 | 周期 | 交付物 |
|------|------|--------|
| 后端 API + 数据模型 | 3 天 | 可联调的 REST API |
| 前端页面 + 交互 | 3 天 | 组合列表/详情/交易表单 |
| 绩效计算 + 看板 | 2 天 | ECharts 可视化 |
| 定时任务 + 联调测试 | 2 天 | 完整功能上线 |

**总计：约 10 工作日**
