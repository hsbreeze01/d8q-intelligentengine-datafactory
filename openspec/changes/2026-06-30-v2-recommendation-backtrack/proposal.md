# Proposal: 推荐回溯验证

## Summary
在每日推荐页面新增「历史回溯」Tab，展示系统历史推荐的实际市场表现（T+1/T+3/T+5/T+10收益率），计算并公开展示推荐系统的胜率和超额收益。通过透明化推荐效果，建立用户信任，为后续付费功能奠定基础。

## Motivation
D8Q已具备每日荐股能力（基于技术面+趋势+基本面+量能的多维评分），但用户无法判断推荐质量。当前推荐数据「只管推不管验」，缺乏闭环。投资者最关心的问题是「你推的准不准」——这需要用数据回答。

## User Stories
1. **投资者** 希望查看过去30天的推荐记录及实际涨跌，判断系统是否值得信赖
2. **投资者** 希望了解哪个维度（技术/趋势/基本面/量能）的信号最准确
3. **投资者** 希望看到推荐组合vs大盘的超额收益曲线
4. **管理员** 希望监控推荐系统的效果，发现退化趋势及时优化

## Scope
### In Scope
- Shark端存储推荐历史并每日回填T+N实际收益
- Factory端代理历史查询和统计API
- 前端推荐页新增「历史回溯」Tab
- 展示: 历史表格、胜率统计、维度拆解、超额收益曲线

### Out of Scope
- 实时推荐算法优化
- 基于回溯结果的自动策略调参
- 推荐失败案例的AI归因分析（下一版本）

## Success Metrics
- 推荐历史数据覆盖率 > 95%（T+5数据完整率）
- 页面日均PV > 100（推荐页流量提升50%）
- 用户停留时长从30s提升到2min
